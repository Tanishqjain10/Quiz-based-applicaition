# Quiz-Based-Application 🎯

An interactive Java-based Quiz Application developed using Java Swing and OOP concepts.  
This application provides a user-friendly interface for conducting quizzes with features like timers, score tracking, lifelines, and result generation.

---

## 🚀 Features

- ✅ User Login System
- ✅ Interactive MCQ-Based Quiz
- ✅ Countdown Timer for Each Question
- ✅ 50-50 Lifeline Feature
- ✅ Real-Time Score Calculation
- ✅ Rules & Instructions Window
- ✅ Attractive GUI using Java Swing
- ✅ Replay Quiz Option

---

## 🛠️ Tech Stack

- Java
- Java Swing
- OOP Concepts
- Event Handling
- AWT

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Tanishqjain10/Quiz-Based-Application.git
```

2. Open the project in NetBeans / IntelliJ / Eclipse

3. Compile and run

```bash
javac *.java
java Login
```
